LE GRAND TOURNOI DES TIRLIBIBI – V5 images des boîtes

Cette version conserve la recherche ciblée des images de boîtes.

IMPORTANT :
- Remplacer uniquement app.js dans le dépôt GitHub.
- Ne pas modifier config.js, index.html ou les règles Firebase.
- Le bouton « Changer la boîte » a été supprimé volontairement.
- Si aucune image fiable n'est trouvée, le joueur peut choisir « Continuer sans image ».
- Les images sélectionnées sont enregistrées dans le document du jeu et restent disponibles dans les différentes vues.
